# brothers-pack

Update files for a private family Minecraft launcher: a signed manifest, the packwiz pack and
`online.json`. Everything here is generated by a publish script; the launcher checks every file's
signature or sha256 before using it. Nothing here is meant for general use.

Source code for the mods under the GPL or LGPL (in `pack/mods/`) is attached to the `source-*` releases,
one per jar.
